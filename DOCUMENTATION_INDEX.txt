📋 QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

STARTUP:
  • Double-click: C:\WowClassicGrindBot\Start.bat
  • Or: Right-click → Run as Administrator
  • Or: Command line → BlazorServer\bin\Release\net10.0\BlazorServer.exe

ACCESS BOT:
  • Browser opens automatically to: http://localhost:5000
  • If not, manually visit: http://localhost:5000

STOP BOT:
  • Close launcher window (dark console)
  • Or press: Ctrl+C in launcher window
  • Wait for graceful shutdown (5-10 seconds)

CHECK LOGS:
  • View: C:\WowClassicGrindBot\out.log
  • Search for: [ERR] or [FTL] for errors
  • Daily rolling logs with backups

GET HELP:
  • Read: TROUBLESHOOTING.txt (Section 10)
  • Check: out.log file for details
  • Report: GitHub Issues with error details

⚠️  CRITICAL REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════════

BEFORE STARTING BOT:

  1. WoW MUST be running
     - Open Battle.net
     - Click Play
     - Log in and enter game
     - MUST see game world (not login screen)

  2. Character MUST be in game
     - Standing in the world
     - Not in loading screen
     - Not at login screen
     - Fully loaded and ready

  3. .NET SDK MUST be installed
     - Check: dotnet --version
     - Must show: 10.0 or higher
     - Download: https://dotnet.microsoft.com/download

  4. Bot files MUST be at: C:\WowClassicGrindBot
     - Verify folder structure exists
     - Check: BlazorServer, Core, Frontend folders

✓ Check all 4 before starting!

🚨 COMMON FIRST-TIME ISSUES & QUICK FIXES
═══════════════════════════════════════════════════════════════════════════════

"World of Warcraft is not running!"
  → Start WoW, log into character, MAKE SURE you can see the game world
  → Then start bot

".NET SDK not found"
  → Download and install from https://dotnet.microsoft.com/download
  → Restart computer
  → Try again

"Build failed"
  → Right-click Start.bat
  → Select "Run as Administrator"
  → Try again

Browser won't open
  → Manually type in browser: http://localhost:5000
  → This is normal, bot still works fine

"Port 5000 already in use"
  → Edit: BlazorServer\appsettings.json
  → Change: "WebUIPort": 5000 to "WebUIPort": 5001
  → Access at: http://localhost:5001

See TROUBLESHOOTING.txt for more solutions!

💡 PRO TIPS
═══════════════════════════════════════════════════════════════════════════════

1. ALWAYS START WOW FIRST
   Bot cannot work without WoW running with character in game.

2. BOOKMARK TROUBLESHOOTING.TXT
   You might need it - search for specific errors with Ctrl+F.

3. KEEP OUT.LOG OPEN
   Tail of out.log shows what bot is doing - helpful for debugging.

4. MONITOR TASK MANAGER
   Check CPU/Memory if bot seems slow - other apps might be hogging resources.

5. USE RELEASE BUILD
   Bot runs significantly faster with Release build (not Debug).

6. CHECK GITHUB ISSUES
   Other people may have solved your problem - search first.

7. PROVIDE FULL ERROR INFO
   When reporting issues, include error message, out.log, system specs.

8. KEEP SOFTWARE UPDATED
   Check GitHub for latest version with new features and fixes.

9. USE FARM CHARACTERS
   Automation tools may violate ToS - use on farm/throwaway characters.

10. MONITOR PERIODICALLY
    Check bot periodically even if running 24/7 - don't just leave it.
